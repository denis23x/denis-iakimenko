# AGENTS.md

This file provides guidance to Codex (Codex.ai/code) when working with code in this repository.

## Commands

```bash
pnpm dev          # start dev server (clears .astro cache first)
pnpm build        # tsc check + astro build + pagefind index + copy pagefind to public/
pnpm preview      # serve the built dist/
pnpm lint         # eslint
pnpm format       # prettier --write
pnpm format:check # prettier --check
```

There are no tests. The build script is the primary correctness gate (`astro check` runs TypeScript validation).

## Architecture

This is a personal blog built on **Astro 6** (SSG), forked from AstroPaper. Package manager is **pnpm**.

### Content

Blog posts live in `src/data/blog/` as Markdown files. Astro's content collection loader uses the glob `**/[^_]*.md` — files or directories prefixed with `_` are excluded. Posts in subdirectories named `_YEAR/` (e.g. `_2026/`) are excluded from the collection until renamed.

Post frontmatter schema is defined in `src/content.config.ts`. Key fields:
- `pubDatetime` / `modDatetime` — dates used for sorting and scheduling
- `draft: true` — hides the post everywhere except dev mode
- `featured: true` — surfaces the post on the homepage
- `timezone` — per-post override; default is `Asia/Bangkok` (set in `src/config.ts`)

Scheduled publishing: posts with a future `pubDatetime` are hidden until 15 minutes before that time (`SITE.scheduledPostMargin`).

### Site configuration

`src/config.ts` — `SITE` object: site URL, author, OG image toggle, posts per page, edit-on-GitHub URL, timezone, etc.\
`src/constants.ts` — `SOCIALS` and `SHARE_LINKS` arrays with icon components.

### Path alias

`@/` resolves to `src/` (configured in `tsconfig.json`).

### Integrations & plugins

- **TailwindCSS v4** via `@tailwindcss/vite` (not the Astro integration)
- **PWA** via `@vite-pwa/astro` — disabled in dev mode; assets generated by `pwa-assets.config.ts`
- **Sitemap** via `@astrojs/sitemap` — excludes `/tags`, `/archives`, `/search`
- **Pagefind** — full-text search index built after `astro build`, output copied to `public/pagefind/`
- **Remark plugins**: `remark-directive` + `remark-callout-directives` (callout blocks with aliases: `danger→deter`, `success→commend`, `info→assert`), `beautiful-mermaid`, `remark-toc`, `remark-collapse`
- **Rehype plugins**: `rehypeLinkPolicy` (link `rel` attributes), `rehypeWrapTables` (scrollable table wrapper)
- **Shiki** syntax highlighting — themes `min-light-custom` (light) / `github-dark-default` (dark); custom transformers for diff notation, highlights, and filename display

### External services

- **Supabase Edge Function** at `unhtenrcalfzvebisnkj.supabase.co/functions/v1/views` — page view counter, called client-side (disabled in dev mode), implemented in `src/components/Views.astro`
- **Giscus** (GitHub Discussions) — comments widget, lazy-loaded, theme synced with light/dark mode, implemented in `src/components/Comments.astro`

### OG image generation

Dynamic OG images are generated at build time via Satori + `@resvg/resvg-js`. Templates are in `src/utils/og-templates/`. Each post gets a PNG at `/blog/[slug]/index.png`.

### Raw prompt instructions

`src/data/raw/instructions/` contains reusable AI editing prompts (Nora Gal style guide, SEO audit, sales copy). These are not part of the Astro content collection — they're reference documents for content editing workflows.
